# Raj Delight Menu

Menu-only Next.js website for Raj Delight, Chandausi.

The experience opens with the Raj Delight logo, then reveals a full searchable menu with category navigation, prices, dish imagery, light/dark theme, and grid/list views.

Menu and price data is carried over from the main Raj Delight website repository. Price gaps are intentionally shown as “Price not listed” rather than inventing a value.

## Run
```
npm install
npm run dev
```

## Validate
```
npm run typecheck
npm run build
```
